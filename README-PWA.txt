Guitar Practice V5.1 - PWA

Esta carpeta contiene la V5.1 estable preparada para publicarse como PWA.

Archivos:
- index.html
- style.css
- app.js
- manifest.json
- service-worker.js
- icons/

Compatible con GitHub Pages y Cloudflare Pages.

La aplicación continúa usando localStorage para guardar los datos en el navegador.
Exportar los datos desde la aplicación sigue siendo recomendable como copia de seguridad.
