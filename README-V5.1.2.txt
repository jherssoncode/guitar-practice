Guitar Practice V5.1.2

Base: V5.1 + V5.1.1

Novedades:
- Modo oscuro con preferencia guardada.
- Screen Wake Lock: mantiene la pantalla del teléfono encendida durante el metrónomo o una sesión de práctica.
- Reintenta Wake Lock al volver a la aplicación si el navegador lo liberó temporalmente.
- Al finalizar la sesión y detener el metrónomo sin una sesión activa, se libera el Wake Lock.

Compatibilidad:
- Navegadores compatibles con Screen Wake Lock lo mantienen activo.
- En navegadores que no lo soportan, la aplicación continúa funcionando normalmente.
- Requiere HTTPS en producción; GitHub Pages cumple esta condición.

La lógica de V5.1 se conserva.
